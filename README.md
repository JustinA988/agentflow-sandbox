# agentflow sandbox

Throwaway repository used to exercise [agentflow](https://github.com/JustinA988/agentflow).

`add()` in `calc.py` returns `a - b` on purpose, so a test can fail. The open issues and pull requests are leftover runs of that tool, including drafts that paste a pytest log. They are not a product backlog.

This repository is not a library.
